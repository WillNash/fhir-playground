Quick Start

  1. Click New Encounter to enter clinical data for a patient
  2. Fill in demographics, vitals, conditions, medications, and labs
  3. Save the record — it is persisted as raw clinical JSON in SQLite
  4. From the Patient Records list, click Convert to FHIR
  5. The system generates a FHIR R4 Transaction Bundle with all resources
  6. Browse and search raw FHIR JSON in the FHIR Store tab
